Get covalent paths#

Lets load first of all a molecular system to work with in this section:

molecular_system = msm.systems['TcTIM']['1tcd.h5msm']
molecular_system = msm.convert(molecular_system)

msm.info(molecular_system)
form n_atoms n_groups n_components n_chains n_molecules n_entities n_waters n_proteins n_structures
molsysmt.MolSys 3983 662 167 4 167 2 165 2 1

MolSysMT includes a method to get all covalent paths found in the molecular system given by a sequence of atom names. To illustrate how the method molsysmt.topology.get_covalent_paths works lets extract all segments of atoms C, N, CA an C covalently bound in this order (C-N-CA-C):

covalent_paths =msm.topology.get_covalent_paths(molecular_system, path=['atom_name=="C"',
                                                                           'atom_name=="N"',
                                                                           'atom_name=="CA"',
                                                                           'atom_name=="C"'],
                                                  selection="component_index==0")

covalent_paths.shape

(247, 4)

The output is a numpy array 2-ranked where the dimension of the first axe or rank is the number of chains found in the system, and the second rank has dimension 4 (since it chain was chosen to have 4 atoms):

Lets check that the name of the atoms in any of the obtained chains is correct:

msm.get(molecular_system, element='atom', selection=covalent_paths[0], name=True)

['C', 'N', 'CA', 'C']

The atom name specified at each place does not need to be unique, we can introduce variants at any position defining the covalent chain. Lets see for instance how to get all 4 atoms covalent paths where the first three atoms are C-N-CA, in this order, and the fourth atom can either be C or CB:

covalent_paths =msm.topology.get_covalent_paths(molecular_system,
                                                  path=['atom_name=="C"', 'atom_name=="N"',
                                                         'atom_name=="CA"', 'atom_name==["C", "CB"]'],
                                                    selection="component_index==0")

covalent_paths

array([[   2,    9,   10,   11],
       [   2,    9,   10,   13],
       [  11,   16,   17,   18],
       ...,
       [1886, 1889, 1890, 1893],
       [1891, 1896, 1897, 1898],
       [1891, 1896, 1897, 1900]])

msm.get(molecular_system, element='atom', selection=covalent_paths[0], name=True)

['C', 'N', 'CA', 'C']

msm.get(molecular_system, element='atom', selection=covalent_paths[1], name=True)

['C', 'N', 'CA', 'CB']

The covalent paths defining the \(\phi\), \(\psi\), \(\omega\) and , \(\xi_1\) dihedral angles are obtained as follows:

# Covalent paths defining all phi dihedral angles in the molecular system
phi_chains = msm.topology.get_covalent_paths(molecular_system, path=['atom_name=="C"', 'atom_name=="N"',
                                                          'atom_name=="CA"', 'atom_name=="C"'])

# Covalent paths defining all psi dihedral angles in the molecular system
psi_chains = msm.topology.get_covalent_paths(molecular_system, path=['atom_name=="N"', 'atom_name=="CA"',
                                                          'atom_name=="C"', 'atom_name=="N"'])

# Covalent paths defining all omega dihedral angles in the molecular system
omega_chains = msm.topology.get_covalent_paths(molecular_system, path=['atom_name==["CA","CH3"]', 'atom_name=="C"',
                                                            'atom_name=="N"', 'atom_name==["CA", "CH3"]'])

# Covalent paths defining all chi1 dihedral angles in the molecular system
chi1_chains = msm.topology.get_covalent_paths(molecular_system, path=['atom_name=="N"', 'atom_name=="CA"',
                                                           'atom_name=="CB"', 'atom_name=="CG"'])
