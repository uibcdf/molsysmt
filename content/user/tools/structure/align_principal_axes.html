Aligning principal axes#

Target axes are supplied as the rows of a right-handed orthonormal matrix. Alignment is rejected when principal moments are degenerate because the individual axes are then not unique. Use weights='masses' when physical inertia axes are intended.

import molsysmt as msm
import numpy as np

crd = msm.systems['POPC']['popc.crd']
psf = msm.systems['POPC']['popc.psf']
molsys = msm.convert([crd, psf])

msm.info(molsys)
