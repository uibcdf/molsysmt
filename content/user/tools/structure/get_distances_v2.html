molsysmt.structure.get_distances#

Calculating distances between atoms and groups.

API documentation

Follow this link for a detailed description of the input arguments, raised errors, and returned objects of this function: molsysmt.structure.get_distances().

The Essentials#

The get_distances() function is a high-performance kernel for geometric analysis. It can calculate distances between single atoms, centers of mass, or arbitrary points in space.

import molsysmt as msm
from molsysmt import systems

lysozyme = systems['T4 lysozyme L99A']['181l.bcif.gz']

# Get distance between the first and the tenth atom
dist = msm.structure.get_distances(lysozyme, selection=0, selection_2=10)
print(f"Distance: {dist}")

Data Integrity & Output Shape#

By default, get_distances() returns a 3D NumPy array (or a puw.Quantity wrapping it) with the shape:

\[[n\_structures, n\_selection, n\_selection\_2]\]

Tip

If you only care about specific pairs of atoms (e.g. atom 0 with 1, and atom 5 with 6), use the pairs=True argument to get a 2D result of shape [n_structures, n_pairs].

Advanced: Periodic Boundary Conditions#

If the system has a periodic box defined, MolSysMT will automatically apply the Minimum Image Convention (MIC) to ensure physical distances are correct.

# To force PBC awareness or ignore it:
# dist = msm.structure.get_distances(lysozyme, selection=0, selection_2=10, periodic=True)
