# Prepared PDBQT recipe contract

Preserve `cookbook-native-pdbqt`, explicit `pdbqt_text:` strings, the separate
typed torsion tree, source indices versus serial IDs, supplied charges/types,
the angstrom boundary and all-H retention. Parsing and writing must not be
presented as chemical preparation or complete connectivity perception.

Link implemented named assignment and torsion tools without enabling them
implicitly. Keep strict-loss behavior, conservative reporting, unsupported
dialects and H5MSM 0.5's rejection of nonempty MolecularMechanics explicit.
Contextual examples require a caller-supplied prepared ligand; executable
fidelity evidence belongs to `tests/form/file_pdbqt/`.
