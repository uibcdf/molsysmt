# Coordinate Delivery Recipe Contract

Preserve the explicit distinction between a molecular-system input and a
unit-bearing coordinate value. Keep direct assignment to one selected target
structure, the atom-level XYZ query and the documented default system-level
refusal. Preserve physical values, axis order, units, unsupported-rank limits
and the caller's responsibility for declared atom correspondence. Do not infer
chemistry or positional identity from array shape.
