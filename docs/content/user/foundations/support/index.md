# Supported

Welcome to **Supported**, the foundational module detailing MolSysMT's interoperability matrix across data forms, physical-chemical data, molecular mechanics, selection syntaxes, 3D visualization engines, and third-party ecosystem bridges.

---

## Contents

- **{doc}`forms/index`**  
  Matrix of supported data representations spanning object classes, disk files, and string inputs.

- **{doc}`physchem`**  
  Supported physical-chemical properties, atomic attributes, element classifications, and physical units.

- **{doc}`molecular_mechanics`**  
  Supported force fields, water models, implicit solvents, and non-bonded interaction parameters.

- **{doc}`selection_syntaxes`**  
  Supported atom and residue selection syntaxes (MolSysMT, AMBER, MDAnalysis, PyTraj) and configured shortcuts.

- **{doc}`viewers`**  
  Supported 3D rendering backends (MolSysViewer, NGLView, Py3Dmol) and environment compatibility.

- **{doc}`third_party_bridges`**  
  Supported third-party library bridges (MDTraj, OpenMM, MDAnalysis, ParmEd, PyTraj, BioPython, OpenFF, RDKit, NetworkX).
