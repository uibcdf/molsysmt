## 📜 Editorial Rules & Layout Standards
- **Section Layout**: Must maintain 4 distinct H2 sections (`## Atomic Properties`, `## Chemical State and Charges`, `## Biophysical and Residue Scales`, `## Surface Accessibility and Volumetric Observables`).
- **Table Formatting**: Each section MUST present a 4-column left-aligned table (`Attribute / Property`, `Target Scope`, `Description`, `Canonical Unit`).
- **Attribute Naming**: Attribute keys MUST be formatted as lowercase code blocks (e.g. `` `sasa` ``).
- **Physical Units**: Physical units MUST be explicitly stated using PyUnitWizard standard canonical units (`nm`, `Da`, `e`, `kJ/mol`, `nm²`, `nm³`).
