# The Entrance

Welcome to **The Entrance**, your gateway to mastering MolSysMT. This foundational module introduces the core mission of the library, step-by-step installation instructions, hands-on first steps, a bird's-eye view of the functional toolbox, and the pre-packaged demo systems available for immediate testing.

Whether you are configuring your environment for the first time or exploring bundled molecular structures to run your first scripts, these 5 units provide everything needed to start working with MolSysMT efficiently.

---

## **Units**

- **{doc}`molsysmt_mission`**  
  Learn about the form-agnostic philosophy, mission, and key architectural goals of MolSysMT.

- **{doc}`installation`**  
  Step-by-step guide to installing MolSysMT via Conda, Pip, or source with optional dependencies.

- **{doc}`first_steps`**  
  A gentle hands-on tutorial loading your first molecular system and running basic operations.

- **{doc}`toolbox_overview`**  
  An organized map of the functional API toolbox (Basic, Build, Topology, Structure, PBC, etc.).

- **{doc}`demo_systems`**  
  Explore the built-in PDB structures and trajectories bundled with MolSysMT for offline testing.
