# Section 02: The Molecular System Directives (`AGENTS.md`)

This guide governs all content under `docs/content/user/foundations/02_molecular_system/`.

## 🧭 Subdirectory Purpose & Scope
Define the core data model of MolSysMT: formal definition of a molecular system, normalization passport, items and forms, forms classification, orthogonal element hierarchy (atom, group, component, molecule, chain, entity), and molecular attributes.

## 📄 Pages List & Paired Micro-`AGENTS.md` Files
- `index.md` ➔ `index.AGENTS.md`: Group landing page with `toctree`.
- `definition.ipynb` ➔ `definition.AGENTS.md`: Formal definition of a Molecular System.
- `normalization.ipynb` ➔ `normalization.AGENTS.md`: Normalization protocols and payload digestion.
- `items.ipynb` ➔ `items.AGENTS.md`: Distinguishing items, containers, and representations.
- `forms.ipynb` ➔ `forms.AGENTS.md`: Form classifications and compatibility.
- `elements.ipynb` ➔ `elements.AGENTS.md`: Orthogonal element hierarchy.
- `attributes.ipynb` ➔ `attributes.AGENTS.md`: Attribute getters, query mechanisms, and data types.
