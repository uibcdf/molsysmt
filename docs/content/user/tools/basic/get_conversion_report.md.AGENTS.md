# Conversion report query contract

Preserve `Tutorial_Get_Conversion_Report`, source immutability and absence of
destination writes, form-agnostic inputs, selection semantics, target-list order,
and the difference between audit coverage and successful conversion. Do not
claim that reports validate optional dependencies or converter-specific options.
Executable regression evidence lives in tests/basic/test_get_conversion_report.py.

Retain the source naming keyword, selected/prospective declarations, topology-
scoped label-only losses and strict pre-write rejection. Do not infer unknown
source context or expand partial audit coverage into an exhaustive claim.
Naming regression evidence: tests/conversion_truth/test_group_naming_fidelity.py.

Preserve named-analysis omission and prospective-context invalidation reporting,
including evaluated-empty versus unevaluated coverage and structure-selection
scope. Neither preflight nor strict refusal mutates the source or recalculates
interactions. Metadata inspection must not decode occurrence columns.
