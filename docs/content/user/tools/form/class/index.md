# Class Forms

In-memory object and container forms supported across MolSysMT native containers and third-party libraries.

---

## Supported Libraries and Containers

| Library / Category | Description |
| :--- | :--- |
| [MolSysMT](molsysmt/index.md) | Native MolSysMT container classes and handlers |
| [OpenMM](openmm/index.md) | OpenMM topology, system, and simulation classes |
| [MDTraj](mdtraj/index.md) | MDTraj trajectory, topology, and file objects |
| [MDAnalysis](mdanalysis/index.md) | MDAnalysis Universe and topology classes |
| [ParmEd](parmed/index.md) | ParmEd structure and topology classes |
| [PyTraj](pytraj/index.md) | PyTraj trajectory and topology objects |
| [Biopython](biopython/index.md) | Biopython PDBStructure and sequence objects |
| [OpenFF](openff/index.md) | OpenFF Molecule and Topology objects |
| [RDKit](rdkit/index.md) | RDKit Mol objects |
| [Viewers](viewers/index.md) | 3D interactive visualization viewer instances |
| [Others](others/index.md) | Array, graph, and external container objects |
