# Chemical-template contract

Preserve `Tutorial_Chemical_Templates`, the exhaustive template/source index map,
independent state selection, absent-field-only transfer, copy/failure semantics,
explicit versus stored-count hydrogen policies, unsupported normalization and
conservative interaction invalidation. The methanol example is an independently
known donor/acceptor control, not a validated conformer. Native inputs do not need
RDKit; the example uses it explicitly as template producer. H5MSM stores chemical
values but not the detached preparation report. Source evidence, template
declarations and optional completed-software credit must remain distinct.
Regression evidence belongs to `tests/physchem/test_chemical_template.py`.
