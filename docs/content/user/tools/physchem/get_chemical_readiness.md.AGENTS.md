# Chemical readiness contract

Preserve `Tutorial_Chemical_Readiness`, detached stored-field assessment,
source indices, incident/crossing bonds, explicit versus virtual hydrogens,
ambiguous/unassociated states, PyUnitWizard coordinate access and bounded
H5MSM 0.5 numeric selections. Availability and declared evidence do not certify
chemical validity or downstream readiness. Never introduce implicit repair or
a universal ready flag. Regression evidence belongs to
`tests/physchem/test_get_chemical_readiness.py`.
