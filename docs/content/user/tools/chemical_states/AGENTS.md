# Chemical States Tools Guide

This directory refines the root, documentation and User Guide Tools instructions.
Keep state-dependent graph tools here; stable sequence tools remain in topology.
Preserve each tutorial's paired content contract, anchor, examples and figures.

Explain selected states, missing/unknown/complete graph distinctions, source
indices, required external context and experimental scientific limits. Reuse
ChemicalStates for storage and general geometry/PBC/physchem tools for their own
operations. Do not describe Topology as a chemical authority. Covalent graphs,
cycle bases, chemical aromaticity, planarity and detected interactions are distinct.
Retain explicit cut/participation rules, IUPAC torsion definitions and independent
analytical controls. Namespace migration must not change scientific profiles.
