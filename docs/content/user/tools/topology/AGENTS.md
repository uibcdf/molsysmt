# Topology Tools Guide

This directory refines the root, documentation and User Guide Tools instructions.
Keep stable inventory/sequence analysis here. Covalent graphs, components, rings
and torsion quartets belong to the chemical_states tools directory.

Sequence tutorials retain source group indices, explicit alignment/identity
semantics, rendered alignments and independent examples. Stable chains do not
follow state-local components. Pure Topology supplies no chemistry through an owner.
