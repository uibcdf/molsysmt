# Developer Hub Governance: `docs/content/developer/` (`AGENTS.md`)

This guide governs all content under `docs/content/developer/`.

---

## 🧭 Purpose and Scope
Provides contributor- and developer-facing documentation on architecture, workspace setup, testing, diagnostics, and editorial standards.

## 🔒 Governance and Style Rules
- All text must be written in English.
- No ampersands (`&`) or emojis/colored icons in titles and headings.
- Preserve all normative editorial rules in `docstrings.md` and `references.md`.
- Keep example commands clear, reproducible, and modern (Python 3.11+, pyproject.toml, pytest).
