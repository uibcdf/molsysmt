# Developer Diagnostics And Telemetry Documentation Agents Guide

This document defines guidelines for documentation files under `docs/content/developer/diagnostics_and_telemetry/`.

## Rules

- All documentation must be written in English.
- Use MyST Markdown format (`.md` or `.ipynb`).
- Do not use `&` in titles; use `and` or direct descriptive titles.
- Do not use colored icons or emojis in document titles.
- Preserve all existing technical content, architecture diagrams, and examples.
- Ensure all `diagnostics_and_telemetry/index.md` toctrees are synced and maintain frictionless navigation.
