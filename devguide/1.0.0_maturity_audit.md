## 🔍 Sprint Finding: The Coverage Gap & "The Great Cleanup"
During the 0.14.0 stabilization (Phase 3), we executed a massive internal audit of the conversion and extraction mechanisms to resolve deep-seated architectural frictions. The test suite went from 1,600+ crashes to less than 10 isolated, highly specific failures.

### Key Achievements (Recently Completed):
1. **Getter Segregation & Semantic Consistency**: Successfully split monolithic `get.py` modules across all forms into `get_topological_attributes.py`, `get_structural_attributes.py`, and `get_mechanical_attributes.py`. We eradicated thousands of circular imports, fixed recursive imports (`from .to_X`), and restored `get_mechanical_attributes.py` for containers like `MolecularMechanicsDict`.
2. **Hierarchical Integrity in Native Topology**: Rebuilt the Native `Topology` engine. Functions like `rebuild_components` and `rebuild_chains` now correctly propagate indices down to both atoms and groups. This solved severe dimensional mismatches during conversions from OpenMM.
3. **Structural Robustness in Native Structures**: Rewrote `Structures.append` to be linear and indestructible. Upgraded `n_atoms` and `n_structures` to dynamic `@property` methods, preventing desynchronization. Insulated internal logic from upstream `pyunitwizard` API changes (using raw NumPy extraction + unit injection) and gracefully handled empty iterables.
4. **File Handler Polymorphism**: Hardened all file-based forms (Amber `.prmtop`/`.inpcrd`, Gromacs `.gro`/`.xtc`, `.dcd`, `.h5`, PDBs, etc.). Converters now strictly check `isinstance(item, (str, os.PathLike))` and dynamically instantiate the underlying reader (e.g. `openmm.app.PDBFile` or `mdtraj.formats.HDF5TrajectoryFile`), curing dozens of legacy `AttributeError` crashes.
5. **Multiple Conversion Shortcuts (Lazy Loading)**: Resolved severe `ImportError` and `RecursionError` circular dependencies on startup by moving the multi-file conversion shortcuts (`_multiple_conversion_shortcuts`) to lazy loading inside `molsysmt.basic.convert`.
6. **Network IO**: Fixed recursive copy bugs in `string:pdb_id` to allow seamless downloading and extraction of CIF/BCIF forms.

## 🛠️ Updated Mandates for Final 1.0.0

### 1. The Great Cleanup (Phase 3 Priority)
It is no longer enough to add new tests. We must **prune the dead wood**. 
- Old tests that are redundant with Contract Tests must be deleted.
- Tests that are "broken by design" (due to architectural upgrades) must be refactored or removed to ensure a clean, meaningful coverage report.

**Remaining Technical Debt to Clear (The Final 10 Failures):**
1. **The "15 vs 10" Component Mismatch**: An edge case in `t4_lysozyme_L99A.h5msm` where `get_molecule_name` inference yields 15 entities but the topological molecules table allocates 10. Blocks full visualizer parity (`nglview.NGLWidget`).
2. **The OpenMM PDBFile Iteration Bug**: In the conversion from `file:pdb` to OpenMM Modeller, `openmm.app.pdbstructure.PdbStructure` is throwing `TypeError: 'PDBFile' object is not iterable` because it expects a raw file stream, not an already instantiated `PDBFile` object.
3. **Trajectory Topology Extraction**: Handling `NotWithThisFormError` properly when `get_n_atoms_from_system` is called on pure coordinate forms (`mdtraj.XTCTrajectoryFile`, `mdtraj.DCDTrajectoryFile`, `file:h5`).
4. **File handling in specific conversions**: Final cleanup of `os.PathLike` vs string bugs in paths being passed to `stat` or external loaders (e.g., Charmm PSF loader).

### 2. Contract Testing Expansion
- Extend the "Parity Guarantee" suite to all Tier 2 forms (RDKit, BioPython).
