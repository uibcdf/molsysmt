# Pedagogical Proposal: Early Introduction of `msm.info()`

## Status
Pending (Evaluating after Module 2 review)

## Purpose
Demonstrate that while the "Form" changes, the biological "Content" remains invariant.

## Motivation
In Module 1, we show `convert()`. Using `msm.info()` immediately after a conversion would allow the user to see that the number of atoms, residues, and chains is identical before and after, reinforcing the "Molecular Form Manager" concept.

## Recommendation
Consider moving basic `info()` usage from Module 5 to Module 1, leaving the advanced features (element-specific reports) for later.
