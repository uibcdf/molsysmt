# Post-Review Notes: Module 12 (Covalent Connectivity)

These points were identified during the Master review on April 21, 2026.

---

### 1. Conceptual Rigor
- **Connectivity vs. Representation:** Ensure the course clearly distinguishes between the physical reality (covalent bonds) and the mathematical representation (NetworkX graphs).
- **Topology Primacy:** Reinforce that connectivity is a property of the **Topology**, and as such, functions from `msm.topology` should be the primary tools for analysis.

### 2. Form Versatility
- **NetworkX as a Form:** Use this module to remind the user that a NetworkX graph is a valid MolSysMT "Form". This means you could (in theory) use a graph as a source for other MolSysMT functions.
