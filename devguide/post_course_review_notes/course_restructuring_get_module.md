# Proposal: Add a dedicated `get()` module to the Common Core

## Status
Pending

## Purpose
Introduce the `get()` function early in the learning journey as the programmatic counterpart to `info()`.

## Motivation
The current course structure introduces `get()` in a specialized way in later modules (e.g., Module 17). However, `get()` is one of the "Golden Quartet" of MolSysMT verbs. Users who learn to select and view systems will immediately want to extract data (coordinates, residue names, etc.) for their own scripts. 

## Recommendation
Insert a new module (suggested **Module 6** or **7**) in the **Common Core** dedicated to the `get()` function. 
- **Focus:** Extracting attributes at different levels.
- **Differentiator:** Contrast it with `info()` (visual vs. data extraction).
- **Shift:** This will require re-numbering subsequent Common Core modules.
