# Roadmap (Developer View)

This roadmap is a curated view of `ROADMAP.md` for developer planning.

## Near Term
- Finalize API stability for 1.0.
- Close documentation gaps in public API and developer docs.
- Stabilize tests and coverage.
- Keep `molecular_dynamics` out of the 1.0 support contract and out of the
  1.0 coverage baseline until it is intentionally promoted later.

## Mid Term
- Extend native attributes and topology coverage.
- Improve MD analysis workflows and integrations.

## Long Term
- Expanded tooling and performance tooling.
- Additional ecosystem integrations.
