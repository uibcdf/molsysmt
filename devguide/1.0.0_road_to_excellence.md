# Road to Excellence (Path to 1.0.0)

This document summarizes the strategic weaknesses and the specific requirements needed to transition MolSysMT from a solid functional library to an industry-standard production framework.

## 1. Strategic Weaknesses

### 1.1 Debugging Complexity (The "Decorator Onion")
The heavy use of stacked decorators (`@signal`, `@arg_digest`, `@dep_digest`, `@lazy_njit`) provides immense power but creates a high barrier for troubleshooting. 
- **Status**: [Mitigated] Standardized structured error context via `smonitor`.
- **Ongoing**: Maintain a clear separation between the "digestion" layer and "business" logic.

### 1.2 Memory Scalability (The Eager Loading Bottleneck)
MolSysMT currently operates on an "in-memory" model for coordinates.
- **Risk**: The library is excluded from Big Data and HPC workflows where trajectories exceed available RAM.
- **Goal**: Post-1.0 development should prioritize an "Out-of-Core" model or a native "Trajectory Iterator" form.

### 1.3 Change Fragility
Because of the highly modular and interdependent nature of the `form/` adapters, non-surgical refactors often have ripple effects in the conversion graph.
- **Mitigation**: Strict enforcement of Contract Testing and the adoption of `MolSysBuilder` for all new test fixtures.

## 2. Requirements for Excellence (Stabilization Checkpoint March 2026)

To declare version 1.0.0 "Rock Solid", the following tasks have been addressed or are in active development:

### 2.1 Elimination of "Bare Excepts" [COMPLETED]
All instances of raw `except:` clauses have been refactored to `except Exception as e:`.
- **Result**: Improved security by preventing the masking of system signals (`KeyboardInterrupt`) and easier debugging.

### 2.2 Advanced Observability and Debug Traceability [COMPLETED/EXPANDING]
The library now supports deep introspection without user-facing noise.
- **DEBUG Signals**: Functions like `is_a_molecular_system` now emit `MSM-DBG-PROBE-001` signals at `DEBUG` level when a form detection fails. 
- **New Task (Total Probe Observability)**: Apply this pattern to all `is_form.py` and `is_item.py` validators across all adapters.
- **Structured Error Context**: `ArgumentError` now supports an explicit `cause` parameter. All argument digesters capture the original exception.

### 2.3 Structural Hygiene and Resource Safety [COMPLETED/ENFORCED]
- **File Descriptors**: Enforced context managers and explicit `.close()` in all handlers.
- **JIT Robustness (Core)**: Implemented explicit casting to `float64` for all inputs in `structure` and `pbc`.
- **New Task (Peripheral JIT Audit)**: Extend the `float64` casting sweep to `molecular_mechanics` and `hbonds` to prevent Numba crashes on unexpected input types.

### 2.4 Stability Advisory System [NEW]
- **Action**: Use SMonitor to emit `INFO` level signals when a user enters an "experimental" module (e.g., `molecular_dynamics`). This manages user expectations and protects the 1.0 stability reputation.

### 2.5 Explicit Support Contract [PENDING]
- **Action**: Finalize the list of Tier 1 forms and modules that fall under the 1.0 stability guarantee.

## 3. The 1.0.0 Release Philosophy

**"Indestructible and Empathetic."**
- **Indestructible**: Mathematically identical results across all forms (Contract Testing) and crash-proof kernels.
- **Empathetic**: Clear diagnostics (even for internal probe misses), fast startup, and honest communication about experimental features.
