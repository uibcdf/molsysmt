# Path-to-1.0 Archive

These documents record audits, plans, and documentation checkpoints produced
during the path to MolSysMT 1.0. They are historical snapshots, even where their
original prose uses words such as "current", "completed", or "authoritative".

No item in this directory is a current release checklist. Consult the root
developer-guide index, current roadmap, code, and tests instead.
