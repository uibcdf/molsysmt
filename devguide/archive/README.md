# Archived Developer Material

Files below this directory are dated snapshots, audits, or assessments. They are
retained for provenance and design context but do not define current behavior.

- `release_1_0/` contains planning and checkpoint material from the path to 1.0.
- `assessments/` contains dated architectural or integration assessments.
- `benchmarking/` contains dated interpretations, comparisons, paper notes, and
  superseded benchmark plans.
- `resolved_bugs/` contains diagnosed defects retained with their implementation
  and regression-test evidence after resolution.

Treat completion labels, test counts, coverage values, capability matrices, and
benchmark numbers as observations at the time of writing. Use current code,
tests, and the maintained normative documents for present-day decisions.
