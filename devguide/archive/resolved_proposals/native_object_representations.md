# Brief native representations

**Reported:** Existing issue #120, selected for implementation on 2026-10-20.
**Status:** Resolved with bounded metadata inspection and explicit unknown counts.

## What

Add repr summaries to all seventeen classes exported by molsysmt.native and
the public Interactions result. Ordinary Python dictionary forms retain Python's
own representation. Unexported legacy placeholder classes and parser subrecords
are outside this surface.

## How

Small class methods use a shared private scalar formatter and read stored lengths,
array shapes, reference metadata and domain presence. They do not call public
get/select/info/copy, restore state tables, build interaction indexes, convert
units, render arrays/DataFrames, enumerate all analyses or read file contents.
Only bounded scalar strings are rendered; arbitrary payload repr is never invoked.

MolSys prefers its present topology/chemical-state atom axis, then structural
shape metadata, then its first interaction analysis. Missing domains and axes
remain None, distinct from zero-length declared data. Structures infer dimensions
from the first available stored shape without validating other arrays. Topology
counts only resolvable reference bonds; ambiguous or absent references yield None.
Interactions show backing relation count, selected occurrences, evaluated structure
count and view status. These are length reads, not view compaction. Dictionary
wrappers summarize payload axes; file handlers describe cached format/open status.

## Why

Default object addresses provide little help, while autogenerated dataclass repr
can expand large dictionaries and numeric arrays. Diagnostics must not trigger
another costly operation or recursively fail by validating a problematic system.
Readable metadata should accompany normal interactive inspection at every size.

## What is measured and what is assumed

Contract tests forbid public dispatch, validators, DataFrame formatting and unit
value extraction while representing native domains. Shape-only and length-only
sentinels describe 100,000 atoms and 10,000 structures but raise on materialization,
iteration or payload formatting. This tests the access boundary, not a benchmark
of a real billion-coordinate allocation. A thousand named analyses are counted
without printing their names. HDF5 data reads and text-buffer reads/seeks are
forbidden while checking open/closed representations.

No timing or memory benchmark claim is made. Inspection work is bounded by a fixed
set of metadata fields, independent of numeric payload size. No compiled routine
is justified for this operation.

## What was refuted

- Reusing info would invoke form dispatch and richer validation/counting.
- Using Structures.n_atoms/n_structures invokes alignment validation.
- Counting distinct relations in a view requires scanning/compacting observations.
- Expanding dataclass data defeats bounded inspection.
- A formatted summary cannot certify valid chemistry, alignment or scientific readiness.

## Scope and exclusions

Human representation only: eighteen classes, one private metadata helper and
corresponding examples/contracts. No serialization shape, copy protocol, query
fast path, validation policy, scientific computation, form or dependency changes.
#128, #121 and #113 remain pending the requested study.

## Acceptance criteria

Accurate dimensions and domain flags; unknown/empty and ambiguous-reference cases;
bounded text for large data; selected sparse view semantics; no mutation, scans,
materialization, secondary-index construction or file reads; preserved persistence
and public signatures; executed Foundations/Toolbox/Cookbook/course examples.

## Provenance

Linux, existing development Python 3.14.7, 2026-10-20. Tests use small deterministic
native fixtures and controlled metadata sentinels; they allocate no giant arrays.

## Diagnostic and lazy-result controls

The first broad native/interaction run passed 1,140 tests but exposed new
SMonitor RuntimeWarnings: formatting constructor arguments could encounter an
initializing Interactions, and patched analyses deliberately have no _positions.
An invalidated analysis also retains backing positions larger than its active
occurrence count. Those cases must not be hidden behind a generic repr fallback.

The final summaries use raw metadata with unknown counts during initialization
and the existing _active_count cache on invalidated/patched results. Private
lazy subclasses use the public Interactions display name. Dedicated controls
forbid _packed() during inspection and protect every public native class before
its constructor has assigned fields. The broad regression treats SMonitor's
argument-summary warnings as errors, while retaining unrelated existing warning
classes. Legacy text-handler test fixtures initialize only the file attribute
needed by their pre-existing destructors before teardown; production destructor
behavior is unchanged.

## Resolution and validation

**Contract-tested:** 1,159 native/interaction cases pass against the final runtime
with `python -m pytest tests/native tests/interactions -n 12 --receptor=llm
 -W 'error:SMonitor signal argument summary failed:RuntimeWarning'`.
All 44 dedicated representation cases pass in that selection. Seventeen native
and interaction doctests pass. The integrated guard selection across #390,
#348, #188 and #120 passes 88 cases, including the final time-only MolSysDict
axis assertion. Unrelated legacy H5MSM, test memory-budget and chemistry-name
warnings remain visible; the introduced SMonitor summary failures are absent.

The eighteen actual repr docstrings and updated class docstrings render with
Sphinx, together with changed guide/course sections, without diagnostics. New
Toolbox, large-data Cookbook and Common Core 04 examples are executed with the
existing interpreter and saved. Original cell code, outputs and metadata are
preserved; missing IDs in the older course notebook are assigned deterministically
when declaring notebook format 4.5. Foundations prose, paired contracts and the
manifest are synchronized. No release or artifact qualification is implied.

Whole-repository Ruff lint/format, public-signature validation (no drift),
docstring fidelity and all fourteen fast release checks pass for this
checkpoint. Inspection does not change any serialization or computational path.
