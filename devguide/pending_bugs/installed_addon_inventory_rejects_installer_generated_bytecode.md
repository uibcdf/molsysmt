# Installed addon bytecode inventory

**Reported:** exact frozen metadata candidate a24b14f3d241893e51703588f9db07a3a70cf11d,
Rust workflow 41730347088, observed 2026-11-03. **Status:** open; owning packaging
repair and local artifact-level reproduction are pending.

## What

The native build/NumPy-floor stages pass, but all four installed-public smoke
jobs fail in `Validate the installed public runtime outside the checkout`.
The inspected Python 3.14 job 126252211540 raises RuntimeError from
`validate_native_viewer_metadata`: its distribution inventory contains addon
`__pycache__/*.pyc` paths, rejected as retired/unreviewed files.

Source: [the original workflow](https://github.com/uibcdf/molsysmt/actions/runs/41730347088).
The source full matrix for this same frozen candidate has since passed all
eight lanes; these different gates keep their separate outcomes.

## How

`validate_installed_molsysmt.py` feeds `distribution.files` directly to the same
exact addon inventory contract used for source/archive payloads. Installed
inventories can include generated bytecode. Compare the original wheel members
and RECORD against a genuine installed distribution before deciding the safe
classification rule. The observed list alone does not establish how each pyc
entered the inventory. Preserve exact reviewed source-file and entry-point checks.

## Why

Installed qualification cannot pass until payload and runtime-generated files
are distinguished correctly. This is separate from #537's tar directory-entry
classification defect. Neither the failure nor successful compilation is evidence
of an incorrect scientific kernel or a qualified installed pair.

## What is measured and what is assumed

GH Run Receptor reports four failed installed smoke jobs and preserves the
workflow's terminal failure. Native job-log inspection confirms the pyc rejection
for Python 3.14. The remaining three logs and original wheel inventory still need
comparison. Installer generation is a likely cause, not yet a local reproduction.

## Scope and acceptance

Reproduce with exact wheel/installed inventories; accept only legitimately
runtime-generated bytecode in the installed context. A wheel/sdist containing
unreviewed source, retired modules, missing required files or inappropriate cache
payload must still fail. Add positive and adversarial guards and rerun actual
installed smoke with immutable source/artifact identities. No broad suffix
whitelist, weakened metadata checks, old-receipt rewrite or public upload is
included. Other matrix skips and historical failures retain their actual status.
