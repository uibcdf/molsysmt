    "In this module, you will learn to manage trajectory fragments using MolSysMT."

    "import molsysmt as msm\n",
    "from molsysmt import systems\n",
    "\n",
    "# Load a simulation trajectory of our enzyme\n",
    "villin_traj = systems['chicken villin HP35']['traj_chicken_villin_HP35_solvated.dcd']\n",
    "villin_topo = systems['chicken villin HP35']['traj_chicken_villin_HP35_solvated.h5msm']\n",
    "molsys = [villin_topo, villin_traj]"
   ]
  },
  {
   "cell_type": "markdown",
   "metadata": {},
   "source": [
    "### 1. Temporal Slicing\n",
    "You can extract specific time windows from your trajectory. For example, let's keep only the last 10 structures, where the system is presumably equilibrated."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "n_structures = msm.get(molsys, element='system', n_structures=True)\n",
    "print(f\"Total simulation structures: {n_structures}\")\n",
    "\n",
    "# Extract the equilibrated part (last 10 structures)\n",
    "equilibrated_traj = msm.extract(molsys, structure_indices=range(n_structures-10, n_structures))\n",
    "\n",
    "print(f\"Equilibrated structures: {msm.get(equilibrated_traj, element='system', n_structures=True)}\")"
   ]
  },
  {
   "cell_type": "markdown",
   "metadata": {},
   "source": [
    "### 2. Striding (Data Reduction)\n",
    "To generate a movie or a quick report, you can take every 10th structure. This reduces the file size by 90% while maintaining the overall narrative of the motion."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "# Sub-sample the trajectory taking 1 structure every 10\n",
    "short_traj = msm.extract(molsys, structure_indices=range(0, n_structures, 10))\n",
    "\n",
    "print(f\"Reduced trajectory structures: {msm.get(short_traj, element='system', n_structures=True)}\")"
   ]
  },
  {
   "cell_type": "markdown",
   "metadata": {},
   "source": [
    "### 3. Merging Trajectory Fragments\n",
    "If your supercomputer job crashed and you had to restart it, you can join the two resulting files into a single virtual object."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "# Simulate two parts of a trajectory; coordinate-only parts may share one topology\n",
    "part_a = msm.extract(molsys, structure_indices=range(0, 10))\n",
    "part_b = msm.extract(molsys, structure_indices=range(10, 20))\n",
    "\n",
    "# Concatenate them\n",
    "full_run = msm.concatenate_structures([part_a, part_b])\n",
    "print(f\"Total concatenated structures: {msm.get(full_run, element='system', n_structures=True)}\")"
   ]
