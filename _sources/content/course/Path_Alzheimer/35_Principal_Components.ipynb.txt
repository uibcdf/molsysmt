    "# Path A - Module 35: Principal Components (PCA) & Axes\n",
    "\n",
    "Molecular trajectories generate thousands of coordinates. Understanding which motions are biologically relevant is like finding a needle in a haystack. \n",
    "\n",
    "In this module, you will learn to use **Principal Component Analysis (PCA)** to simplify the dynamics of your complex and **Principal Axes** to orient your systems in space."
   ]

    "import molsysmt as msm\n",
    "from molsysmt import systems\n",
    "\n",
    "# Load a trajectory for analysis\n",
    "villin_traj = systems['chicken villin HP35']['traj_chicken_villin_HP35_solvated.dcd']\n",
    "villin_topo = systems['chicken villin HP35']['chicken_villin_HP35_solvated.h5msm']\n",
    "molsys = [villin_topo, villin_traj]"
   ]
  },
  {
   "cell_type": "markdown",
   "metadata": {},
   "source": [
    "### 1. Principal Axes of Inertia\n",
    "MolSysMT can find the orientation of your molecule. This is useful to center it and align it with the Cartesian axes (X, Y, Z)."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "# Get the principal axes of the protein\n",
    "axes, moments = msm.structure.get_principal_axes(\n",
    "    molsys, selection='molecule_type==\"protein\"', structure_indices=0, weights='masses'\n",
    ")\n",
    "\n",
    "print(\"Principal Axes vectors:\")\n",
    "print(axes)\n",
    "print(\"Principal moments:\", moments)"
   ]
  },
  {
   "cell_type": "markdown",
   "metadata": {},
   "source": [
    "### 2. Dimensionality Reduction with PCA\n",
    "PCA identifies the directions (eigenvectors) along which the system fluctuates the most. MolSysMT returns them from largest to smallest eigenvalue, so the first row is PC1. Eigenvectors are dimensionless and eigenvalues have squared-coordinate units."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "# Perform PCA on the alpha carbons of the protein\n",
    "eigenvectors, eigenvalues = msm.structure.principal_component_analysis(molsys, selection='atom_name==\"CA\"')\n",
    "\n",
    "print(f\"Eigenvector matrix shape: {eigenvectors.shape}\")\n",
    "print(f\"Variance explained by PC1: {eigenvalues[0]}\")"
   ]
  },
  {
   "cell_type": "markdown",
   "metadata": {},
   "source": [
    "### 3. Aligning to Principal Axes\n",
    "For long systems like the Alzheimer's fibril, it is standard practice to align the longitudinal axis with the Z-axis of the box."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "# Align the protein so its longest axis points towards Z\n",
    "target_axes = [[0, 0, 1], [0, 1, 0], [-1, 0, 0]]\n",
    "molsys = msm.structure.align_principal_axes(\n",
    "    molsys, selection='molecule_type==\"protein\"', axes=target_axes, weights='masses'\n",
    ")\n",
    "print(\"System aligned to principal axes.\")"
   ]
