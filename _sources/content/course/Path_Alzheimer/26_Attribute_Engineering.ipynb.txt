    "# Path A - Module 26: Attribute Engineering (Patching)\n",
    "\n",
    "No matter how good your building tools are, you will often find small errors in your topology: a chain named \"A\" that should be \"P\", or a water residue with a non-standard name. \n",
    "\n",
    "In this module, you will learn to use `set()` to \"patch\" your molecular system on the fly."
   ]

  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "import molsysmt as msm\n",
    "from molsysmt import systems\n",
    "\n",
    "# Load our solvated complex from the previous module logic\n",
    "fibril = msm.convert('pdb:2BEG', to_form='molsysmt.MolSys')\n",
    "peptide = msm.build.build_peptide('KLVFF')\n",
    "complex_sys = msm.merge([fibril, peptide])"
   ]
  },
  {
   "cell_type": "markdown",
   "metadata": {},
   "source": [
    "### 1. Renaming Chains\n",
    "When you merged the fibril and the peptide, they might have overlapping chain IDs or names. Let's make the peptide chain stand out by naming it \"THERAPY\"."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "# Let's identify the chain index of our peptide (it's the last chain after merge)\n",
    "n_chains = msm.get(complex_sys, element='system', n_chains=True)\n",
    "peptide_chain_idx = n_chains - 1\n",
    "\n",
    "# Update the chain name and ID\n",
    "msm.set(complex_sys, element='chain', selection='chain_index=='+str(peptide_chain_idx), \n",
    "        chain_name='THERAPY', chain_id='T')\n",
    "\n",
    "msm.info(complex_sys, element='chain')"
   ]
  },
  {
   "cell_type": "markdown",
   "metadata": {},
   "source": [
    "### 2. Updating Entity Names\n",
    "Entities define the identity of the molecules. Let's rename the \"AMYLOID BETA\" entity to something more scientific for our report."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "# Find the entity index\n",
    "ent_idx = msm.select(complex_sys, selection='entity_name==\"AMYLOID-BETA PROTEIN\"', element='entity')\n",
    "\n",
    "if len(ent_idx) > 0:\n",
    "    msm.set(complex_sys, element='entity', selection=ent_idx[0], name='A-beta Fibril')\n",
    "\n",
    "msm.info(complex_sys, element='entity')"
   ]
  },
  {
   "cell_type": "markdown",
   "metadata": {},
   "source": [
    "### 3. Patching Coordinates\n",
    "`set()` is not only for names. You can use it to update coordinates if you have performed an external calculation (like a rotation or an alignment)."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "metadata": {},
   "outputs": [],
   "source": [
    "import numpy as np\n",
    "\n",
    "# Get current coordinates\n",
    "coords = msm.get(complex_sys, selection='chain_name==\"THERAPY\"', coordinates=True)\n",
    "\n",
    "# Apply a dummy shift of 0.5 nm in the X axis\n",
    "new_coords = coords + np.array([0.5, 0.0, 0.0]) * msm.pyunitwizard.unit('nm')\n",
    "\n",
    "# Patch the system with new coordinates\n",
    "msm.set(complex_sys, selection='chain_name==\"THERAPY\"', coordinates=new_coords)\n",
    "\n",
    "print(\"Peptide coordinates updated successfully.\")"
   ]
