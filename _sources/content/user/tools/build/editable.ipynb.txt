    "# Editable\n",
    "\n",
    "*Creating an editable molecular system builder to modify or construct topologies.*\n",
    "\n",
    "The function {func}`molsysmt.build.editable` serves as the primary entry point to work with the native {class}`molsysmt.MolSysBuilder` container (detailed in the {ref}`MolSysBuilder <user-foundations-native-world-classes-molsysmt-molsysbuilder>` guide).
