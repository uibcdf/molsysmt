# Element

MolSysMT defines an orthogonal hierarchy of structural element tiers to represent molecular topologies at multiple levels of granularity—from individual atoms to macromolecular chains and distinct chemical entities.

|      |      |
| :--- | :--- |
| [Is element](is_element.ipynb) | Validating recognized topological element tiers |
| [Is composed of](is_composed_of.ipynb) | Checking structural containment relationships |
| [Atom](atom/index.md) | Operations for individual atom entities |
| [Group](group/index.md) | Operations for residue and functional group entities |
| [Component](component/index.md) | Operations for covalently connected polymer components |
| [Molecule](molecule/index.md) | Operations for distinct chemical molecules |
| [Entity](entity/index.md) | Operations for molecular species and entity definitions |
| [Chain](chain/index.md) | Operations for structural chains and macromolecular strands |
