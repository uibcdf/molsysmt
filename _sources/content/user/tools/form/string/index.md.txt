# String Forms

In-memory text, sequence, SMILES, and database identifier forms supported by MolSysMT.

| Form | Description |
| :--- | :--- |
| [alphafold_id](string_alphafold_id.ipynb) | AlphaFold DB identifier string |
| [amino_acids_1](string_amino_acids_1.ipynb) | One-letter amino acid sequence string |
| [amino_acids_3](string_amino_acids_3.ipynb) | Three-letter amino acid sequence string |
| [pdb_id](string_pdb_id.ipynb) | Protein Data Bank (PDB) 4-character identifier string |
| [pdb_text](string_pdb_text.ipynb) | PDB-formatted text buffer string in memory |
| [smiles](string_smiles.ipynb) | SMILES chemical structure specification string |
| [uniprot_id](string_uniprot_id.ipynb) | UniProt database accession identifier string |
