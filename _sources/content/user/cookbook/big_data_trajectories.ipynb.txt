    "# Big Data Trajectories\n",
    "\n",
    "*Processing selected coordinate blocks with H5MSM and iterators.*\n",
    "\n",
    "Long molecular dynamics ensembles can exceed available RAM. Select the atoms and\n",
    "structures needed for an analysis, process each block, and discard it before\n",

    "The accumulated analysis output needs its own memory budget.\n",
