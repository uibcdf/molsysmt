class molsysmt.thirds.tleap.tleap.TLeap[source]#

Bases: object

Programmatic interface to write and run AmberTools’ tLEaP scripts. To avoid problems with special characters in file paths, the class run the tleap script in a temporary folder with hardcoded names for files and then copy the output files in their respective folders. .. attribute:: script

Newline characters are added after each command

is neutralized (default is 0).

Parameters:

  • PBRadii (str) – “bondi”, “mbondi” (default), “mbondi2”, “mbondi3” or “amber6” to choose the set of atomic radii for generalized Born or Poisson-Boltzmann calculations.
