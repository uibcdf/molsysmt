# Bounded group-name interpretation profiles

The offline version-1 profiles are generated by
`molsysmt/data/_make/make_group_name_profiles.py`. Run the script from the repository
root, or use `--check` to verify the committed bytes. It reads the pinned primary
reference receipt `devtools/data/name_scheme_profile_review_549_20261104.json` and
the shared amino-acid alphabet authority; it performs no network requests.

- `sequence`: the shared 26-symbol DDBJ code alphabet. XAA/XLE mean X/J here.
- `amber`: the standard twenty names and eight reviewed state labels from the
  pinned AmberClassic amino12 library. SEC/PYL and modified groups are not
  implicitly admitted. Code projection does not assert a builder template exists.
- `ccd`: 36 successfully inspected component records in the 2026-11-04 RCSB API
  snapshot. Thirty admit a peptide-letter projection; six do not. Parent, type,
  original component title, URL and full-response digest are retained. Three
  additional requests returned HTTP 404; this is not proof of universal absence.
- `legacy`: the existing historical MDTraj-derived parent table, plus the shared
  alphabet. The table is reused directly, not copied here or certified as CCD.

The CCD names XAA and XLE identify non-peptide compounds; HID/ASH/CYX also differ
from their Amber meanings. A label without context does not select a convention
for those cases. The standalone public helper credits reached data references
through optional Ackredit; importing the library reads no profile file or
provider. The fixed single-entry lazy cache contains this small immutable asset,
not an unbounded cache of caller systems or group database payloads.

Naming metadata uses the separate declaration registry in
`molsysmt/native/_group_naming.py`. Code 4 adds `sequence` after the original
Amber/CCD/legacy codes. Readers retain the original three-profile wire registry;
a code is interpreted only when its profile was declared in that wire payload.

This data describes name interpretation and parent projection. It supplies no
chemical graph, coordinates, force-field parameters or protonation predictions.
