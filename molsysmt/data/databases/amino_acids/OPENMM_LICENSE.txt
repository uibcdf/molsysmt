OpenMM-derived PDB hydrogen-name reference data

Source: wrappers/python/openmm/app/data/pdbNames.xml
Revision: ba0aa236ac4d07241382869604c4d2ea58c4f3f5
The derived JSON keeps only canonical protein H-name aliases. It is not
an OpenMM reader, replacement engine, chemical-state or group-name table.
The unchanged upstream XML is retained under data/_make/pdb_names/ solely
for offline, hash-verified regeneration under this same notice.
